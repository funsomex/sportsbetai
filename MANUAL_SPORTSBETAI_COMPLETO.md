## 4. VALUE BETS (APUESTAS DE VALOR)

### ¿Qué es un Value Bet?

Un **Value Bet** ocurre cuando la probabilidad real de un evento es MAYOR que la probabilidad implícita en las cuotas. Esto significa que a largo plazo, apostar sistemáticamente a value bets genera ganancias.

### Cómo Interpretar un Value Bet:

| Campo | Significado |
|-------|-------------|
| **Partido** | Equipos que se enfrentan |
| **Selección** | Qué apostar (Local, Visitante, Empate, Over/Under) |
| **Cuota** | El multiplicador ofrecido por la casa de apuestas |
| **Valor %** | Cuánto valor tiene la apuesta (mayor = mejor) |
| **Confianza %** | Nivel de certeza de la IA en su predicción |
| **Casa** | Casa de apuestas que ofrece esa cuota |

### Recomendaciones:
- Busca value bets con **valor > 5%** y **confianza > 70%**
- No apuestes más del **2-5% de tu bankroll** por apuesta
- Mantén un registro de todas tus apuestas

## 6. COMBINADAS (PARLAYS)

### ¿Qué es una Combinada?

Una **combinada** o **parlay** es una apuesta múltiple donde seleccionas varios eventos. Si TODOS aciertan, ganas; si uno falla, pierdes todo.

### Cómo Crear una Combinada:

1. Ve a la sección **"Combinadas"**
2. Haz clic en **"Nueva Combinada"**
3. Selecciona los partidos y mercados que quieres incluir
4. El sistema calculará automáticamente la cuota total
5. Ingresa tu stake (cantidad a apostar)
6. Guarda la combinada para trackearla

### Fórmula de Cuota Total:
```
Cuota Total = Cuota1 × Cuota2 × Cuota3 × ...
```

### Ejemplo:
- Partido 1: Real Madrid gana @ 1.50
- Partido 2: Lakers gana @ 1.80
- Partido 3: Djokovic gana @ 1.40

**Cuota Total:** 1.50 × 1.80 × 1.40 = **3.78**

Si apuestas $10, puedes ganar $37.80

| **Implied Probability** | Probabilidad que sugiere la cuota: 1/cuota × 100 |

## 12. FÓRMULAS ÚTILES

### Probabilidad Implícita:
```
Probabilidad Implícita (%) = (1 / Cuota) × 100
```
Ejemplo: Cuota 2.00 → (1/2.00) × 100 = 50%

### Value Percentage:
```
Value (%) = ((Probabilidad Real / Probabilidad Implícita) - 1) × 100
```

### ROI:
```
ROI (%) = ((Ganancias Totales - Stakes Totales) / Stakes Totales) × 100
```

### Criterio de Kelly (Stake Óptimo):
```
Stake (%) = ((Probabilidad × Cuota) - 1) / (Cuota - 1)
```
