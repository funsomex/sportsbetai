================================================================================
                              CONSEJOS DE USO
================================================================================

1. PROTEGE TU CUOTA DE API
   Evita recargar la página constantemente. El caché de 60 minutos
   garantiza datos frescos sin gastar requests innecesariamente.

2. REGISTRA TUS RESULTADOS
   Usa el sistema de tracking para marcar tus combinadas como
   ganadas o perdidas. Esto te dará métricas reales de tu rendimiento.

3. USA EL FILTRO DE FECHAS
   Al generar combinadas, filtra por "Hoy" o "Mañana" para obtener
   partidos más relevantes y con cuotas más estables.

4. DIVERSIFICA DEPORTES
   El generador de IA funciona mejor cuando tiene variedad de
   partidos para analizar. Prueba con diferentes deportes.

5. NIVEL DE RIESGO
   - Bajo: Favoritos claros, cuotas bajas, mayor probabilidad
   - Medio: Balance entre valor y seguridad
   - Alto: Underdogs y cuotas altas, mayor riesgo/recompensa
